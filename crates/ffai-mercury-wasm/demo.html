Mercury — speech recognition in the browser

Pure Rust on WebAssembly. No whisper.cpp, no ONNX Runtime, no server.

1 · Weights

Supply the three files from a Whisper checkpoint — nothing is bundled or fetched for you. whisper-tiny.en is the one to start with.

2 · Audio

Any file the browser can decode. It is resampled to 16 kHz mono here, by the browser's own resampler — the module deliberately does not ship one.

Load the three model files and an audio file to begin.
