Carmenta — OCR in WebAssembly

Pure Rust. No Tesseract.js, no ONNX Runtime Web — detection, recognition and reading order are all inside the wasm module.

Weights are yours. There is no filesystem in a browser, so the files below are handed to the module as bytes.

mobiledet-crnn — the pair that measured fastest in a wasm runtime: ppocrv5-mobile-det/det-fused.safetensors (4.7 MB) and crnn-english-g2/crnn.safetensors, from your FFai model cache.

Leave "one line" ticked. Detection is ~89 % of the work and wasm has no SIMD yet, so a full page read takes minutes; recognizing a crop you already selected takes about 200 ms. See the README.
