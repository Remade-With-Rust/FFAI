DETERMINISTIC count, re-runnable: how many hand-written kernels exist, where
each is gated, and what runs when the gate is closed. The rule from
`codec-vectorize-kernel`: a kernel that is not wired to the shipping path is
the commonest and costliest defect, so the census comes before any new twin.

## Where the campaign stands on non-x86

Every x86 kernel above keeps an `unreachable!` stub on other targets, and the
runtime predicate that guards each call returns `false` there, so aarch64 and
wasm32 run the candle three-op fallbacks for attention and the f32 `Linear`
path for projections. `tests/veins_reachability.rs` asserts the kernels are
REACHED on an AVX2 box for the shipped shapes and DECLINE elsewhere; the
cross-target `cargo check` of the crate is the compile gate for the stubs.
NEON / simd128 twins of `decode_head`, `F16Gemv` and the int8 GEMV are the
open work of this vein — they cannot be gated bit-identical on this box, so
they are not claimed here.
